# Issue tracker: GitHub

Track issues and specs in https://github.com/mujak27/k8s-custom-controller-deployment using the gh CLI. Specify --repo mujak27/k8s-custom-controller-deployment when outside its clone or worktree.

- Read an issue body, comments, labels, and dependency state before working on it.
- Create one issue per approved ticket; use ready-for-agent for fully specified agent work.
- Represent blockers using native GitHub issue dependencies, with a human-readable Blocked by section in the issue body. If native dependencies are unavailable, the issue body is authoritative.
- Start only when all blocking issues are closed. A ready-for-agent label alone does not mean a blocked issue can start.
- Link any issue or change being worked on to the OpenChamber session as soon as it is known.
- Publish findings and checks before closing an issue. Leave unrelated or parent issues unchanged.

PRs as a request surface: no.
